# Facebook Layout Project

This is a mini project that simulates a Facebook-like layout, including a login/start page and a feed page.  
It was built as a team assignment using HTML and CSS.

## 📁 Project Structure

- `facebook.html` – Main landing page
- `FacebookFeed.html` – Feed page layout
- `facebook.css` – Styles for the landing page
- `FacebookFeed.css` – Styles for the feed
- `images/squishi.jpeg` – Sample profile picture

## 🛠 Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons

## 📦 How to Use

1. Click the green `Code` button and choose `Download ZIP`
2. **Extract** the downloaded ZIP file to a folder
3. Open `facebook.html` or `FacebookFeed.html` in your browser
